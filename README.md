# 🚀 Portfólio de IA & MVPs - Behring Founders 2026 - Este repositório centraliza as soluções tecnológicas e protótipos funcionais desenvolvidos por mim para a aplicação do Ciclo 2 do programa Behring Founders. Todas as ferramentas foram projetadas visando eficiência de custos, utilizando Python, a biblioteca Librosa para áudio e a API gratuita do Google AI Studio (Gemini 1.5 Flash). ## 🛠️ Projetos Desenvolvidos ### 1. ScoreBuddy AI * **Objetivo:** Feedback pedagógico e musical em tempo real para estudantes. * **Tecnologias:** `Python`, `librosa` (DSP), `Google AI Studio API`. * **Como funciona:** O script extrai as frequências cromáticas de um arquivo de áudio e utiliza LLM para sugerir correções de postura e dedilhado. ### 2. ManausEstoque AI * **Objetivo:** Prevenção de desperdício de alimentos em mercadinhos locais em Manaus. * **Tecnologias:** `Python`, `datetime`, `Google AI Studio API`. * **Como funciona:** Calcula produtos que vencem em até 15 dias e gera automaticamente estratégias de "Promoção Relâmpago" personalizadas para o WhatsApp do comércio. ### 3. ManausRotas * **Objetivo:** Otimização logística urbana e economia de combustível para motoboys locais. * **Tecnologias:** `Python`, `Google AI Studio API` como motor de roteamento geográfico. * **Como funciona:** Ordena sequencialmente múltiplos endereços com base na realidade geográfica dos bairros de Manaus. ### 4. Soluções de Produtividade Corporativa * **InboxFlow AI:** Classificador e resumidor inteligente de e-mails corporativos. * **Triagem Ágil:** Sistema B2B para RH avaliar compatibilidade de currículos com vagas de emprego.
